# Applications

PXP is one program with several applications, as in NX. Switching changes
the ribbon and navigators. The part stays open, and nothing is copied or
reloaded.

| Application | Key | Stage |
| --- | --- | --- |
| Modeling | Ctrl+M | 0 (primitives), 1 (full) |
| Drafting | Ctrl+Shift+D | 2 |
| Manufacturing | Ctrl+Alt+M | 3 |
| Post Processor Generation | | 4 |
| Machine Kit Builder | | 4 |
| CAE | | 5 |

The **Application** ribbon tab lists them all. Shortcuts can be changed
in [Customer Defaults](customer-defaults.md).

**Roles** (resource bar): Essentials shows the Home tab only, Advanced
every tab.
