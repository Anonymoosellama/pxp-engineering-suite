# Viewing

## Mouse (NX)

| Gesture | Action |
| --- | --- |
| MB2 drag (wheel pressed) | Rotate |
| MB2 + MB3 drag, or Shift + MB2 drag | Pan |
| MB1 + MB2 drag, or Ctrl + MB2 drag | Zoom (drag down to zoom in) |
| Wheel | Zoom about the cursor |
| MB1 click | Select |
| MB2 click | OK in the open dialog |
| MB3 click | Context menu (Information, Fit, Snap View) |

A click that moves less than 4 pixels is still a click, so MB2 = OK never
rotates the view by accident.

## Keys and the View menu

| Key | View |
| --- | --- |
| Home | Trimetric |
| End | Isometric |
| F8 | Snap to the nearest standard view |
| Ctrl+F | Fit |

The **View** menu on the top border bar also offers Top, Front, Right,
Back, Bottom and Left. It has edge and silhouette display toggles,
Perspective, a **Section** clip along X, Y or Z at an offset, and **Named
views**: type a name and press Save to store the current view, then click
a name to return to it. Named views last for the session.
