# Information

Right-click a feature in the Part Navigator, or use MB3 in the graphics
window with a body selected, and choose **Information**. It shows the
feature's name, type, state and, if it failed, why. For solids it also
shows mass properties at unit density: volume, surface area and centroid,
in the part's units, computed from the exact B-rep by the geometry kernel
named in the window.
