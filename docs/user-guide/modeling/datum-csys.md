# Datum CSYS

**Home › Feature › Datum CSYS.** Creates a datum coordinate system at the
WCS origin, aligned with the absolute axes. Every new part starts with
`Datum Coordinate System(0)` at the absolute origin. Datums are drawn as
red, green and blue axes. Dynamic placement (dragging, offset from other
objects) arrives with sketching in Stage 1.
